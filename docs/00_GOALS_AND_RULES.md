## 기술 선택 (새 프로젝트에서 구현)
- React + Vite; TypeScript 도입 여부는 Codex가 파일·구현량 점검 후 제안 가능. 별도 승인 없는 Next.js 전환 금지.
- 정밀 커스텀 CSS, Recharts, Lucide. shadcn/ui·Tailwind는 불필요하면 설치하지 않음.
- Vercel 대상. 서버 측 API 프록시/서버리스 route 필요. `vite preview`와 `npm run build`만으로 배포용 비밀키 프록시가 생기지는 않음.
- Playwright 1672×941 screenshot + 기능 검사. 원본 스크린샷을 그대로 이미지 배경으로 넣는 방식 금지.

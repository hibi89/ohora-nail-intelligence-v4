## 기능·브라우저 검사

- 실제 snapshot KPI 24 / 87 / 18 / 58 및 `Oct 2 – Oct 12, 2026` 범위를 표시했다.
- 검색은 한 태그 차원 값으로 13개 게시물을 찾았고, 임의 미일치 문자열은 “No posts match” 빈 행을 표시했다. 검색을 비우고 전체 결과를 복원했다.
- `Last 7 calendar days in sample`은 `Oct 6 – Oct 12, 2026` 범위를 선택했다. `All observed dates`로 최초 범위를 복구했다.
- Trend / Color Distribution / Tag Coverage가 각각 콘텐츠를 교체했다.
- 디자인 카드와 게시물 썸네일에서 상세 dialog가 열렸다. Escape로 닫혔다. 원본 게시물 링크의 보안 속성을 확인했으나 외부 링크는 실행하지 않았다.
- 디자인 필터 적용 시 게시물 표가 23행으로 바뀌고 필터 초기화 뒤 24행을 복구했다. 날짜 정렬은 오름/내림 동작을 확인했고 24행이 내부 스크롤 컨테이너에서 접근 가능하다.
- 상세 보기의 실제 분석 이미지 `naturalWidth > 0`을 확인했다. 최종 Chrome 콘솔 오류 0, 경고 0.
- 개발 API GET은 HTTP 200, 정규화 응답 24 posts / 97 slides를 반환했다. 자동화된 API unit test는 GET-only 동작을 검사한다.

## 레퍼런스와 남은 시각 차이

1. 레퍼런스 사진 원본은 킥오프 자료에 없어 히어로·사이드바·인사이트·시그니처 슬롯이 CSS 추상 placeholder다. 각 슬롯에 `pending-generation` 배지를 표시한다. 실제 브랜드 캠페인 사진과 비교할 때 가장 큰 시각 차이다.
2. 디자인 카드와 표 썸네일은 올바르게 매칭된 실제 분석 이미지를 사용하므로 레퍼런스의 샘플 제품 사진, 모델, crop과 다르다.
3. 원본 폰트 파일은 없고 웹폰트를 외부에서 불러오지 않았다. Georgia/OS 기본 serif 및 시스템 sans fallback을 사용하므로 자폭·줄바꿈·획 대비가 원본 폰트와 다를 수 있다.
4. 실제 기간과 값, 데이터 경고, 태그 라벨이 표시된다. 레퍼런스의 2024년 날짜, 샘플 KPI, 비교 상승률, 공유 수, 경쟁/인과 문구는 사용하지 않았다.
5. 데이터에 명시 플랫폼이 없어 표는 `—`를 표시한다. Shares 컬럼은 생략했다. Excel은 STEP 4용으로 disabled다.

따라서 레이아웃 정합도는 높지만 자산·서체·실제 데이터 표기 차이가 남아 있다. 99% 수치나 픽셀 동등성은 주장하지 않는다.

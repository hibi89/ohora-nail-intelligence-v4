# OHORA v4 — STEP 1 미결정 사항

> **진행 상태:** 아래는 STEP 1/2 당시의 선택지와 미결정 이력이다. STEP 3 최종 지시로 적용한 UI 정책은 [STEP 3 구현 보고서](V4_STEP3_IMPLEMENTATION.md)와 [STEP 3 미해결 사항](V4_STEP3_OPEN_ISSUES.md)을 기준으로 한다. 아래의 과거 “결정 필요” 문구를 현재 구현에 대한 미완료 주장으로 읽지 않는다.

## STEP 3 지시로 적용된 사항

- 기간은 전체 관측 기간으로 시작하고 모든 데이터 영역을 같은 Asia/Seoul 범위로 필터한다.
- 디자인 카드 이름/정렬은 `Most Observed Designs` 빈도순, 동률 라벨순이다.
- 조합 도넛 분모는 자격을 갖춘 73개 디자인 슬라이드이며 부적격 14개는 주석으로 보여 준다.
- Today's Insight는 선택 범위의 최다 조합과 count/분모만 보여 준다.
- 검색은 캡션과 6개 태그 차원을 사용한다.
- 플랫폼은 명시 필드가 없으므로 `—`, Shares는 표시하지 않는다.
- 장식 자산 정책 A는 별도 생성이며 이번 UI는 4개 pending-generation 플레이스홀더를 사용한다.
- Excel은 STEP 4까지 비활성 상태다.

아래 본문은 당시 실제 데이터 검증만으로 확정할 수 없던 제품 선택지와 계량 근거를 보존한다. 현재 남은 판단만 정리한 목록은 [STEP 3 미해결 사항](V4_STEP3_OPEN_ISSUES.md)이다.

## STEP 2 지시로 확정된 기준

- KPI 1 `Total Analyzed Posts`: AI 슬라이드가 1개 이상 연결된 고유 게시물 ID 수. 현재 24.
- KPI 2 `Trending Designs`: 선택 기간의 디자인 판정 슬라이드 수. 현재 87. 이 숫자는 성장률이나 전 기간 대비 변화량이 아니다.
- KPI 3 `Active Colors`: 디자인 슬라이드에서 관측된 고유 색상 라벨 수. 현재 18.
- KPI 4 `Top Tags`: 카테고리명을 포함한 고유 `(category, tag)` 쌍 수. 현재 58.
- 기본 참여율 집계: 유효한 게시물별 원본 참여율의 단순 평균(유효 n과 전체 n 병기). 가중 참여율도 별도 ViewModel 값으로 유지한다.
- 장식 이미지 출처: 정책 A, 분석 사진과 별개인 생성 이미지. STEP 2에서는 슬롯만 정의하고 생성하지 않는다.

위 기준은 숫자 상수로 저장하지 않으며 JSON에서 다시 계산한다. 구현과 분모는 [지표 정의](V4_METRIC_DEFINITIONS.md)를 따른다.

## 지표 정의

1. **Trending Designs의 의미**
   - KPI 숫자 기준은 확정: 선택 기간의 디자인 슬라이드 수. 이를 시간에 따른 상승/하락으로 읽지 않는다.
   - 별도 5개 카드의 정렬 기준은 디자인 조합의 관측 빈도로 구현했다. `Trending` 문구를 유지할지 더 정확한 문구로 바꿀지는 화면 단계에서 확인한다.
   - 근거: 현재 12일만 있고 직전 7일 구간은 7건/5일뿐이며 2일 미관측이다. 비교 성장률은 신뢰할 수 없다.

2. **Active Colors KPI**
   - 확정 기준: 선택된 날짜 범위의 디자인 슬라이드에서 고유 색상 라벨을 센다. 현재 전체 범위는 18종이다.
   - 색상 출현 294회는 분포/상세 지표로 분리하며 KPI 값으로 사용하지 않는다.

3. **Top Tags KPI**
   - 확정 기준: 고유 `(category, tag)` 쌍 58개를 센다. 같은 문자열이 다른 차원에 나타나면 별도 태그로 유지한다.
   - 문자열만 센 57개 및 총 출현 643회는 보조 품질/분포 값으로 둔다.

4. **Trending Nail Designs 상위 5개 기준**
   - 후보 기준: 디자인 슬라이드의 조합 출현 순위, 모티프 출현 순위, 태그 조합 출현 순위.
   - 기존 어댑터 방식은 색/기법/모티프 중 2개 이상이 채워진 이미지별 조합을 세며, 현재 73개 슬라이드가 69개 조합으로 나뉜다. 상위 횟수 3·2·2·1·1로 동률이 많다.
   - 결정할 것: 조합에 포함할 태그 차원, 최소 표본 수, 동률 정렬, 카드 대표 이미지(최초 인덱스/최근 날짜/별도 선택), 제목의 생성 방법. 게시물 좋아요를 슬라이드별 성과처럼 복제하지 않는다.

5. **Design Combination Trends 도넛 분모**
   - 후보 A: 조합 조건을 만족한 디자인 슬라이드 73개. 상위 5개 9건(12.33%), 기타 64건(87.67%). 조합 불충족 디자인 슬라이드 14개는 별도 표기.
   - 후보 B: 디자인 슬라이드 전체 87개. 조합 불충족 14건을 별도 범주로 추가해야 합계가 맞는다.
   - 후보 C: AI 슬라이드 전체 97개. 비디자인 10건도 들어가므로 “디자인 조합”의 의미와 맞는지 결정 필요.
   - 상위 5개/기타만 그리는 경우 분모와 기타 정의를 도넛 중앙이나 보조 문구로 표시한다.

6. **Engagement 표시 기준**
   - 원본은 게시물별 `(likes + comments) / followers * 100`과 23/23 정확히 일치한다.
   - 유효 23개 평균의 평균(단순 평균) 후보는 1.0583%. 총 반응 합계를 총 팔로워 합계로 나눈 가중 후보는 0.3567%다.
   - STEP 2 기본값: 화면 평균은 단순 평균 1.0583%이며 유효 표본 23/24를 함께 제공한다. 합산 가중률 0.3567%는 별도 필드로 둔다.
   - 팔로워 수가 게시 시점 기준인지와 향후 KPI/차트에서 가중률로 변경할지는 데이터 사양 확인이 필요하다.

7. **게시물과 캐러셀 디자인 판정**
   - 게시물 단위 23/24가 디자인으로 판정됐지만, 그중 2개는 디자인/비디자인 슬라이드가 섞여 있다.
   - 결정할 것: 게시물 표의 디자인 여부를 게시물 AI 필드로 표시할지, 슬라이드별 결과에서 “디자인 슬라이드가 하나 이상”으로 재계산할지. 두 값을 서로 덮어쓰지 않는다.

## 표시·기간·시각 자산

8. **날짜 시간대와 기간 경계**
   - STEP 2 기본 계산은 UTC 날짜 및 양 끝 날짜 포함이다. 전역 날짜 범위 기본값은 스냅샷의 전체 관측 범위, Overview 기본값은 최신 관측 날짜 기준 7일이다.
   - 화면에서 Asia/Seoul 또는 브라우저 시간대로 바꿀지는 구현 전에 결정한다. 현재 최신 관측 날짜는 2026-10-12 UTC다.

9. **Today's Insight 문구**
   - 선택 A: 결정론적 관측 요약(상위 조합/태그와 건수, 유효 표본 수).
   - 선택 B: UI에서 인사이트를 생략하고 데이터 범위 안내를 표시.
   - 비교/인과/경쟁사 문구와 `2.3x` 같은 값은 데이터가 없으므로 사용하지 않는다. 자연어 생성 또는 최소 표본 임계치가 필요하면 승인된 규칙을 별도로 정한다.

10. **플랫폼·공유 열**
    - `platform`과 공유 수 필드는 현재 JSON에 없다. 현재 permalink 호스트는 모두 Instagram이지만 명시 필드가 아니다.
    - 결정할 것: URL 호스트 allowlist로 플랫폼 배지를 파생해도 되는지, 또는 플랫폼을 숨길지. 공유 열은 추가 데이터가 확보될 때까지 제거해야 한다.

11. **이미지 표시 및 정적 장식 자산**
    - 장식 자산 정책 A(분리 생성)가 확정됐다. STEP 2는 빈 슬롯/manifest만 만들었다.
    - 분석 JSON URL은 슬라이드 97/97에서 정확 인덱스 자산 URL과 일치하지만 실제 브라우저 fetch/권한/장기 URL 안정성은 시험하지 않았다.
    - 원본 분석 이미지의 hotlink 허용/저장 방식과 공개 권한 확인은 화면 구현 전에 결정한다. 장식 슬롯에는 분석 사진을 넣지 않는다.

## 검색·내보내기 계약

12. **검색 범위**
    - 후보: 캡션 + 여섯 AI 태그 차원 + 날짜. 게시물 링크/ID 검색은 내부 사용에 한정.
    - 결정할 것: 사용자가 “keywords”로 기대하는 대상 및 매칭 방식(부분 문자열/정규화/태그 정확 일치).

13. **Excel 5개 시트**
    - 다운로드 기능 자체는 현재 데이터로 만들 수 있지만, 5개 시트의 이름과 행 단위는 정해져 있지 않다.
    - 기존 구현 계획의 제안 초안: 디자인 인사이트, 게시물, 이미지, 캐러셀, 분석 품질. 승인 전 확정하지 않는다.
    - 결정할 것: 열 목록, 날짜 필터 적용, null 표시, 집계 공식/분모 표기, 캡션과 원본 URL 포함 여부, 슬라이드 없는 자산 3건의 수록 위치, 비공개 파일의 접근/보존 정책.

## STEP 3–4 화면/내보내기 전에 남은 결정

이 항목들은 STEP 2 데이터 계층을 막지 않는다. 해당 화면 또는 내보내기를 구현하기 전에 제품 표현을 확정한다.

- 도넛의 조합 필드·분모는 코드에서 `조합 자격 슬라이드` 기준으로 명시했으며, 화면에 적용하기 전 승인한다.
- 플랫폼 배지를 permalink 호스트에서 파생해 표시할지, Shares 열을 제거할지.
- 화면 날짜를 UTC 또는 다른 시간대로 표시할지.
- Today's Insight의 결정론적 문구와 최소 표본 기준.
- 검색 범위와 정규화 규칙.
- Excel 5개 시트의 행/열 계약 및 비공개 캡션·링크 포함 범위.
- 분석 이미지 URL 표시/저장 정책과 별도 생성 장식 자산의 실제 생성 산출물 검토.

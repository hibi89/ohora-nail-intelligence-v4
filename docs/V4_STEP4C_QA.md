## 기능/예외 검증

- Excel 시트 이름과 순서: `디자인 인사이트`, `게시물`, `이미지`, `캐러셀`, `분석 품질` 5개.
- Node 테스트에서 실제 `.xlsx` 바이트 생성 후 다시 읽어 필터된 게시물/슬라이드 행 수, 6개 태그 컬럼, 원본 슬라이드 인덱스 순서, 빈 결과, 수식처럼 보이는 캡션의 리터럴 셀 처리를 확인했다.
- 실제 브라우저 다운로드 파일도 열어 검증했다. 검색 `환절기만`, 날짜 2026-10-08, `Matched thumbnail available` 필터 조합은 게시물 1행과 AI 슬라이드 1행을 내보냈고, 메타데이터에 해당 검색어·날짜·필터가 기록되었다. 5개 시트 이름이 모두 일치했고 수식 셀은 0개였다.
- 최종 구현을 담은 최신 다운로드 파일을 다시 파싱해 시트별 본문 행 수를 확인했다: 디자인 인사이트 6, 게시물 1, 이미지 1, 캐러셀 0, 분석 품질 23. 전역 미연결 자산 건수 항목이 품질 시트에 있고, 다섯 시트 전체 수식 셀은 0개였다. 파싱용 임시 복사본은 검증 직후 제거했다.

## 보안/변경 경계

`data/private/`는 Git ignore 대상이다. Excel 내보내기는 정확 매칭된 이미지 URL만 담고, 미연결 asset URL·원본 envelope·인증정보를 포함하지 않는다. 수식 셀은 생성하지 않으며 브라우저 다운로드 동작만 사용한다. 기존 `dashboard2`, 포트 5180의 서버, n8n, DB, API 인증정보 및 외부 배포에는 변경이 없다.

## 제한

생산용 배포/API/권한/갱신 체계는 이 단계의 범위가 아니다. 개발 API는 V4 `npm run dev`에서만 제공된다. 원본 platform 필드는 없으므로 표시는 검증 가능한 Instagram permalink에서 추론한다. shares와 비교 기간 데이터는 없어 수치/성장률을 생성하지 않는다.

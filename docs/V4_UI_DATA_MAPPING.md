# OHORA v4 — 레퍼런스 UI ↔ 실제 JSON 매핑 (STEP 1 기록)

> 이 문서는 STEP 1 당시 데이터만으로 분류한 초안이며 STEP 3의 구현/제품 결정을 반영하지 않은 기록이다. 현재 구현은 [STEP 3 구현 보고서](V4_STEP3_IMPLEMENTATION.md), 실제 브라우저 검증은 [STEP 3 시각 QA](V4_STEP3_VISUAL_QA.md), 남은 항목은 [STEP 3 미해결 사항](V4_STEP3_OPEN_ISSUES.md)을 기준으로 한다.

분류 기준: **A** 현재 JSON에서 직접 읽음, **B** 현재 JSON 집계/변환, **C** 추가 데이터 또는 기획 결정을 먼저 필요로 함, **D** 현재 자료로 해당 값을 만들 수 없음. C/D는 참고 변형이나 지원 가능한 하위 요소를 별도로 적었다.

## 핵심 KPI와 인사이트

| 레퍼런스 요소 | 등급 | 실제 원천 및 계산 후보 | 확인된 결과와 제한 |
|---|---|---|---|
| Total Analyzed Posts | **B** | 선택 범위에서 AI slide가 1개 이상 있는 고유 `postId` 수. 전체 스냅샷에서는 24. | 24. 관측 게시물 총수와 AI 성공 게시물 수가 다른 경우 분석 성공 게시물을 기준으로 센다. |
| Trending Designs KPI | **B** | `is_design_post === true`인 AI 슬라이드 수. 전체 스냅샷은 87. | 분류와 집계는 구현 가능하다. 이 값은 디자인 슬라이드량이며 시간에 따른 상승세가 아니므로 성장률은 제공하지 않는다. |
| Active Colors KPI | **B** | `ai.slides[].color[]`의 고유 값 수 또는 색상 출현 수. 날짜 필터 적용 후 재집계 가능. | 색상 18종, 출현 294회, 색 태그 있는 슬라이드 87/97. 추천 후보는 “관측 색상 종류 18”; “활성”의 기간 범위는 결정 필요. |
| Top Tags KPI | **B** | 색/기법/질감/모티프/시즌/용도 전체에서 고유 `(category, tag)` 쌍 수. 전체 스냅샷은 58. | KPI 기준은 카테고리 구분 고유 태그 수로 확정했다. 문자열만 센 57개와 태그 출현 643회는 다른 지표다. |
| Today's Insight | **C** | 태그/조합 출현의 관측 요약은 변환으로 가능. 예: 최다 조합의 관측 건수와 표본 수를 기술. | 응답은 인과관계, 경쟁사, 성장률을 제공하지 않는다. 레퍼런스의 “2.3x higher engagement this week”는 현재 JSON으로 뒷받침되지 않는다. 중립 요약의 문구/최소 표본 기준 결정 필요. |
| Trending Nail Designs 5 cards | **C** | `is_design_post=true`인 슬라이드에서 조합 또는 모티프 출현수로 상위 5개를 선택하고 같은 슬라이드 URL을 대표 이미지로 사용하면 B 변형 가능. | 현재 조합 후보(색+기법+모티프 중 2개 이상)는 73 슬라이드/69 조합, 상위 횟수 3·2·2·1·1이다. 다수 동률이라 이름/대표 사진의 동률 처리 및 “trending”→“most observed” 표현 결정 필요. 큐레이션된 디자인 이름 필드는 없다. |
| Design Combination Trends 도넛 | **C** | 슬라이드별 색+기법+모티프 조합을 세고 상위 5+기타 비율을 계산 가능. | 기존 어댑터 규칙(세 차원 중 채워진 그룹이 2개 이상)을 적용하면 적격 73/87 디자인 슬라이드, 고유 조합 69개다. 상위 5개는 9/73=12.33%, 나머지 적격 조합 64/73=87.67%. 14/87 디자인 슬라이드는 조합 자격 미달. 분모가 73인지 87인지, 자격 미달을 별도 표시할지 결정 필요. |

## Analyzed Posts 표

| 화면 열/요소 | 등급 | 원천/계산 | 제한 |
|---|---|---|---|
| Date | **A** | `timestamp` | 24/24 유효. UTC→화면 시간대, 날짜 경계 포함 규칙 결정 필요. |
| Platform 아이콘 | **C** | 원천에 `platform` 필드 없음. `permalink` 호스트를 검증해 표시하는 변형은 가능. | 현재 24/24 호스트가 Instagram. 저장된 명시 필드가 아니며 TikTok 게시물은 없다. URL 호스트 파생 허용 필요. |
| Post Image | **B** | 같은 게시물의 첫 번째 디자인 슬라이드(또는 첫 슬라이드) URL을 선택. `postId + index`로 연결. | 대표 사진 우선순위 정의 필요. 97개 슬라이드 URL은 문법상 유효하지만 브라우저 네트워크 로딩/권한은 이 감사에서 시험하지 않았다. |
| Caption / Keywords | **B** | 게시물 `caption`과 선택 슬라이드의 태그 배열을 합쳐 검색/표시. | 태그 6차원 중 어떤 것을 키워드로 요약할지 결정 필요. 캡션 원문은 사용자 비공개 콘텐츠로 로그에 넣지 않는다. |
| Detected Colors | **B** | 슬라이드 `color[]`; 색상 라벨을 색상 칩으로 표현. | 색 이름을 실제 HEX 색으로 변환하는 팔레트/색상 샘플은 JSON에 없음. 임의 HEX 지정 금지. |
| Tags | **B** | `technique`, `texture`, `motif`, `season`, `use` 및 필요 시 `color`. | 다수 태그가 배열에서 비어 있음. 태그 없는 행에 임의 태그를 채우지 않는다. |
| Likes / Comments | **A** | 게시물 `likes`, `comments` | 좋아요 1건 결측, 댓글 24건 유효. |
| Shares | **D** | 해당 원천 필드 없음 | 공유 숫자는 표시할 수 없다. 컬럼 제거 또는 추가 원천 결정. |
| Engagement | **B** | 게시물 원본 `engagement` 값으로 유효값 단순 평균을 계산. 23/24 유효, 현재 1.0583%. 가중 비율은 별도 제공. | 원천 값 자체는 직접 제공되지만 화면 집계는 변환이다. 유효 표본 수를 함께 표시하며 두 평균을 혼용하지 않는다. |
| 원본 링크 | **A** | `permalink` | 안전 프로토콜/호스트 검사 뒤 사용. 계정/게시물 URL을 문서나 로그에 기록하지 않는다. |

전체 표를 스크린샷과 똑같이 만들려면 Shares 및 명시적 Platform에 추가 자료/결정이 필요하므로 표 전체 판정은 **C**다. Likes/Comments/Engagement로 대체하는 경우 수치를 Shares 열에 넣어서는 안 된다.

## 데이터가 아닌 레퍼런스 장식/제품 크롬

- 사이드바 메뉴, 상단 프로필/알림, 검색 입력 장식은 분석 JSON에서 오지 않는 정적 UI다. 사용자 이름·알림 수·배지 값을 레퍼런스 샘플에서 실제 값처럼 복사하지 않는다.
- 히어로와 세로 프로모션 카드는 문구/사진이 분석 JSON 필드가 아니다. 현재 `reference/`에는 확정 스크린샷만 확인되므로, 장식 이미지로 사용할 승인 자산 또는 데이터 슬라이드 선택 정책이 필요하다.
- 레퍼런스의 날짜, KPI 값, 좋아요, 비교 퍼센트, 2.3배 주장은 시각 예시이며 실제 출력값으로 재사용하지 않는다.

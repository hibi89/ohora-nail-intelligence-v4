# OHORA Nail Intelligence v4 — 픽셀·레이아웃 명세

## 기준과 측정 신뢰도

- 기준 이미지: `reference/ohora_target_1672x941.png`, 1672 × 941 px, RGB. 원점을 좌상단으로 잡고 좌표는 `[x, y, width, height]` 형식으로 적었다.
- 이미지를 실제로 열어 영역 경계를 읽었고 대표 표면 픽셀은 원본에서 샘플링했다. 카드의 얇은 외곽선과 사진의 부드러운 경계는 육안 측정이므로 표의 경계값은 대체로 ±2–4 px 오차가 있다. 구현 단계에서 원본과 나란히 놓고 보정한다.
- 캡처는 고정 데스크톱 뷰포트다. 1672 × 941에서 스크롤 0, 100% 배율로 최초 정합을 맞춘다. 화면 크기가 달라질 때의 반응형 규칙은 원본으로부터 추정하지 않고 사용성을 위한 별도 설계로 둔다.

## 색·타이포그래피

원본 PNG의 대표 픽셀/영역 빈도를 확인한 값과 화면을 보고 잡은 후보를 구분한다. 아래 값은 새 UI의 시작 토큰이지 이미지에 쓰인 모든 색의 정확한 추출값은 아니다.

| 용도 | 시작값 | 근거 |
|---|---|---|
| 사이드바 바탕 | `#F4E7E0` | 사이드바에서 가장 많이 나온 실제 픽셀 `(244, 231, 224)` |
| 상단 바 바탕 | `#FAF5F1` | 상단 바에서 가장 많이 나온 실제 픽셀 `(250, 245, 241)` |
| 카드/밝은 면 | `#FDFAF7` | 메인 콘텐츠에서 가장 많이 나온 실제 픽셀 `(253, 250, 247)` |
| 선택 메뉴 | `#F0DCD0` 근방 | 화면에서 읽은 연한 피치 후보, 세부 픽셀은 보정 필요 |
| 본문 잉크 | `#302722` 근방 | 안티앨리어싱된 글자 외곽을 보고 잡은 후보, 원본 폰트/색상 코드 미확인 |
| 보조 문구 | `#88766D` 근방 | 화면에서 읽은 낮은 대비의 웜 브라운 후보 |

| 강조 팔레트 | 로즈 `#D99491`, 피치 `#E8C5B4`, 코코아 `#76513F` 근방 | 아이콘, 도넛, 링크용 시각 후보. 실측 토큰으로 단정하지 않음 |

타이포는 세리프 중심이다. 브랜드와 히어로 제목은 큰 대비의 고전적 세리프, 카드 제목·메뉴·표도 세리프 계열로 보인다. 영문 `Nail Intelligence`는 약 52–56 px, 섹션 제목 17–19 px, 메뉴/표 13–15 px, KPI 값 29–32 px 정도다. 이미지에 폰트 파일이나 메타데이터가 없어서 실제 폰트 이름과 라이선스는 확인되지 않았다. 구현 시 상업 사용 가능한 후보와 한글 글리프를 함께 비교하고, 실제 폰트 로딩 후 줄바꿈과 자간을 보정한다.

## 상호작용 상태로 보이는 요소

- 검색 입력과 날짜 범위 선택
- 좌측 7개 메뉴의 선택 상태
- 히어로 카드 외에는 View All / View Details 이동 동작
- KPI의 기간 비교 영역(비교 기간의 실제 데이터가 있을 때만 값 표시)
- 트렌드 이미지, 태그, 좋아요 오버레이
- 조합 도넛 범례
- 표 전체 선택·행 선택·필터·Excel 다운로드·행 메뉴
- 차트 기간 선택, 3개 탭, 범례와 hover 툴팁
- 알림과 프로필 드롭다운

STEP 0에서는 화면만 관찰했으며 버튼 동작이 확정된 것은 아니다. 실제 구현 때 기능 명세 및 데이터 계약과 맞춰 클릭/키보드 동작을 정의한다.

## 이미지에서 그대로 복제하면 안 되는 내용

전체 PNG를 앱의 배경이나 UI 이미지로 쓰지 않는다. 히어로, 사이드바, 조합 카드에 보이는 사진을 개별 원본으로 제공하는 자료도 킥오프 폴더에서 찾지 못했다. 이 사진들은 출처/사용권을 확인한 별도 이미지 또는 승인된 생성 이미지로 교체하고, 인스타그램 썸네일은 접근 실패·URL 만료·공개 범위에 대응하는 빈 상태를 제공한다.

`12,847`, `328`, `24`, `156`, `+23%` 등의 KPI, 디자인 이름·좋아요 수, 2.3배 인사이트, 도넛 비율과 10월 날짜 차트는 레퍼런스의 시각 예시다. 실제 응답으로부터 같은 의미를 산출하지 못하면 그대로 복사하거나 표시하지 않는다.

## 구현 후 비교 순서

1. 같은 1672 × 941 뷰포트와 100% 배율, 스크롤 0, 폰트 로딩 완료 상태를 맞춘다.
2. 사이드바와 상단바 경계, 콘텐츠 좌우 여백, 네 개 행의 카드 경계를 맞춘다.
3. 타이포 크기·행간·줄바꿈과 사진 crop을 맞춘다.
4. 도넛, 탭, 표 열, 차트의 위치와 밀도를 보정한다.
5. 마지막으로 테두리·그림자·아이콘·색조를 보정하고, 좁은 화면에서 카드가 겹치지 않는지 별도 확인한다.

# OHORA Nail Intelligence v4 — STEP 4-C 남은 결정

## 구현을 위해 선택한 기본값

1. **시트 이름/행 단위** — STEP 3에서 제안된 다섯 시트 이름(`디자인 인사이트`, `게시물`, `이미지`, `캐러셀`, `분석 품질`)을 적용했다. 이미지 시트는 원본 asset 100행 대신 AI 슬라이드 97행이며, 캐러셀 시트는 캐러셀로 판정된 게시물만 한 행씩 담는다. 검토 시 시트 구성이나 열 계약 변경이 필요한지 확인해 달라.
2. **내보내기 범위** — 검색·서울 기간·게시물 테이블의 두 필터·현재 정렬을 반영한다. 체크박스 선택은 내보내기 filter로 쓰지 않는다. 모든 선택 게시물의 AI 슬라이드를 원래 인덱스 순으로 내보낸다.
3. **디자인 전용 필터** — 기존 계약대로 게시물의 `is_design_post`를 사용한다. 혼합 캐러셀을 “디자인 슬라이드가 1장 이상 포함된 게시물”로 재분류하지 않는다.
4. **플랫폼** — 명시 필드가 없어 검증된 HTTPS Instagram permalink에서만 `Instagram`을 표시한다. 현재 데이터는 24/24건이 이 규칙을 통과한다. 별도 플랫폼 원천 필드가 추가되면 우선순위를 다시 정할 수 있다.

## 데이터가 제공하지 않아 미구현인 수치

- `shares`는 24/24건 모두 결측/미제공이며 Excel에도 빈 값 대신 해당 지표 자체를 새로 만들지 않는다.
- 이전 비교 기간이 없으므로 성장률·증감 화살표를 계산하지 않는다.
- 매출, 경쟁사 점유율, 실제 인기/시장 전체 수치는 데이터에 없으며 합성하지 않는다.
- 3개 미연결 원본 이미지 자산은 `분석 품질`에 전역 건수로만 보고하고 URL은 노출하지 않는다. 전역 snapshot 품질 숫자는 현재 선택 게시물 filter와 무관하다고 이름과 설명에 표시한다.

## 아직 남은 운영 결정

- Excel 파일은 사용자의 브라우저 다운로드 위치에 저장된다. 프로젝트 내 보관·서버 저장은 구현하지 않았다.
- 개발 API는 private JSON을 로컬 개발 시 읽는다. 배포 환경의 데이터 공급, 접근 제어, 갱신/캐시 정책은 별도 단계에서 정의해야 한다.
- 이미지 CDN의 장기 접근과 외부 표시 권리는 보증되지 않는다.
- 네 장식 이미지는 생성 대기 슬롯이며 STEP 4-C에서 건드리지 않았다.

위 항목은 현재 STEP 4-C의 안전한 데이터 경계와 STEP 3 계약을 유지한 채 작업하기 위한 선택 및 범위 한계다. 검토 후 시트 이름/열/필터 의미 변경이 필요하면 다음 승인 단계에서 정할 수 있다.
